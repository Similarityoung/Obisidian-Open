# 实习产出与协作

两篇文章的阅读摘记。

## 推动事情发生，成为项目的 owner

来源：[如何推动事件发生，成为项目的 owner](https://www.woshipm.com/zhichang/5235141.html)。

- 了解协作者实际负责什么、关心什么，通过沟通建立联系。
- 明确各方目标、职责和当前进度，用共享文档保持信息同步。
- 遇到协作阻碍时先讲清原因；需要向上沟通时，带上事实和依据。
- 方法之外，推动事情仍然需要真实的投入。

## 通过实习形成成果

来源：[如何通过一次实习获得转正](https://zhuanlan.zhihu.com/p/1911262854318920310)。转正也受招聘名额影响，下面讨论的是个人能做的部分。

| 项目类型 | 工作重点 |
| --- | --- |
| 功能修改 | 稳定交付，通过多个需求积累可信度 |
| 模块实现 | 设计先行，重视质量和多轮 Code Review |
| 独立服务 | 理解需求、比较方案、演示原型，再根据反馈迭代 |
| 探索项目 | 提前验证不确定性，及时与导师调整方向 |

具体做法：记录工作进展；用图说明复杂关系；回顾代码问题；会前准备议程和材料，会上推动需要做出的决定。图可以用 draw.io、Excalidraw 或 C4 表达，清楚比形式重要。
