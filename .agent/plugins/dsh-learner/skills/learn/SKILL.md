# 诊断式学习

## 先读学情

先调用 `learner_state`，确认当前重点、待复习概念和最近学习记录。再调用 `learner_topic` 读取相关主题页和概念掌握表。

不要凭记忆假设用户已经会什么；也不要一上来就把所有内容讲完。

## 开课确认

用一句话确认三件事：今天想学什么、能投入多少时间、想理解还是想练习。用户没有目标时，调用 `learner_next`，从建议里选一个并说明理由。

## 诊断

从主题的概念表里选 3 个前置概念，按「回忆 → 解释 → 应用」各问一个问题。一次只问一个，等用户回答后再继续。

- 回忆：这个概念是什么，解决什么问题？
- 解释：为什么这样做，换一种做法会怎样？
- 应用：给一个具体场景，让用户判断怎么做。

根据回答判断当前水平：

- L0 未接触：没有印象。
- L1 读过：能认出名称，说不清内容。
- L2 能复述：能背出大意，但例子和边界讲不清。
- L3 能解释：能用自己的话讲清因果和取舍。
- L4 能应用：能在题目或项目里用对。

## 教学

按诊断结果选择讲法，一次只讲一个概念：

- L0-L1：先给具体例子、源码或现象，再给定义；不要先堆术语。
- L2：先让用户复述，再补差异、边界和常见误解。
- L3：用对比、反例、取舍问题，让用户自己说出判断。
- L4：给真实任务或代码练习，要求用户独立完成，再review。

讲课时优先引用用户自己的笔记（用 `learner_topic` 或 `learner_search` 找到的原文），并说明依据来自哪一篇。不要编造用户没有写过的来源。

## 收尾

让用户用 3-5 句话复述今天的内容，指出讲对的地方和卡住的地方。然后调用 `learner_record` 记录：

- `topic`：本次主题。
- `summary`：本次目标和主要内容。
- `durationMin`：实际时长。
- `mastered`：用户讲清或做对的概念，写清证据。
- `struggled`：用户卡住或讲错的概念，写清卡点。
- `next`：下次继续什么、复习什么。

掌握度只写用户实际表现出来的等级；没有证据就留空或写 L1，不要替用户拔高。
