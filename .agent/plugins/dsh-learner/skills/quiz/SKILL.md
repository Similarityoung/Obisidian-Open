# 出题与评分

1. 调用 `learner_next` 或 `learner_state`，优先选待复习和 L1-L3 的概念。
2. 调用 `learner_topic` 和 `learner_search` 找原文依据，不要出笔记里没有依据的题。
3. 出 3-5 题，覆盖三种类型：回忆、解释、应用；一次只问一题，等用户回答后再继续。
4. 每题反馈说清三件事：对在哪里、缺什么、依据哪一段笔记。不要只给“对/错”。
5. 结束后调用 `learner_record`：
   - 答对且能解释的放 `mastered`，写清证据。
   - 答错或漏掉的放 `struggled`，写清卡点。
   - `next` 写下一次复习重点。

如果用户答不出，先给一个提示或更简单的例子，不要直接公布答案；用户仍然答不出时再讲解，并把该概念记为 struggled。
