# 间隔复习

1. 调用 `learner_next`，取得到期概念；没有到期就从 L2-L3 里选 3 个。
2. 先让用户不看笔记，用自己的话讲；讲不清时给一个提示，不要直接给答案。
3. 每个概念 1-2 分钟，按「是什么 → 为什么 → 怎么用」追问，记录用户讲对和卡住的点。
4. 复习结束后调用 `learner_record`：
   - `mastered` 写讲清的概念和证据。
   - `struggled` 写仍然卡住的概念。
   - `next` 写下一次复习时间或练习建议。
5. 最后用一句话总结：今天巩固了什么、下次什么时候再复习。
