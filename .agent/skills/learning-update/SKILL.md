# 学习画像增量更新

画像在 `Learning/`：`学习状态.md` 是总目录，其余每页一个主题。

## 依据怎么算

- 笔记（含 AI 整理）说明学过什么。
- 笔记开头「我的理解」一节、讨论中的回答和实践，说明能讲出来、用得上。
- 每条判断写确认日期。

## 步骤

1. 读 `Learning/学习状态.md`，拿到末尾“上次整理”的 commit。
2. 运行 `git log <commit>..HEAD --name-only --format=` 和 `git status --short`，列出新增或修改的笔记；跳过 `Learning/`、`.agent/`、`.claude/`、`.obsidian/`。
3. 判断每篇笔记属于哪个主题。已在主题页依据中链接过、内容只是小改的笔记，跳过。
4. 再加上本次对话中用户的回答和实践（如有）。
5. 只改受影响的主题页。主题页按“大类 > 细类 > 元信息”组织：
   - 细类一行一个：`- 名称：一句话要点 · [[笔记#标题|简称]]`。
   - 元信息结构待定，目前只记来源链接；定下来后再补。
   - 笔记涉及的细类不在页面中时，直接加一行；需要新的大类时，经用户同意后添加。只写现状，历史交给 Git。
6. 同步改总目录中对应主题的一行，并把“上次整理”改为当前 HEAD 的短 hash 和日期。
7. 先把改动列给用户确认，再写入。

## 主题调整

- 笔记不属于现有主题：建议新建主题页或归入相近主题，经用户同意后执行。
- 主题页超过一屏：建议拆分。
- 长期没有新依据的主题：建议移到“暂无活跃学习”。
- 新建主题页沿用现有页面的结构和元数据：`title`、`date`、`draft: true`、`tags: [learning]`；不填 `type`、`slug`，不发布到博客。
