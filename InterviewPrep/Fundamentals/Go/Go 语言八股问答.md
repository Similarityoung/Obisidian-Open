# Go 语言八股问答

## 进程、线程和协程有什么区别？

**回答：**

- **进程**是操作系统分配资源和提供隔离的基本单位，拥有独立的虚拟地址空间及进程资源。
- **线程**是操作系统调度执行的基本单位。同一进程中的线程共享地址空间和大部分进程资源，但各自有栈和寄存器等执行上下文。
- **协程**是由语言或运行时管理的执行单元，通常比线程轻量。具体的调度和切换方式取决于语言及运行时实现。
- **Goroutine** 是 Go 运行时管理的并发执行单元。Go 调度器将大量 goroutine 复用到操作系统线程上运行，并通过 P 提供调度所需的资源；goroutine 与 OS 线程不是一一对应的。

简要来说：**进程管资源与隔离，线程由操作系统调度执行，协程由语言或运行时管理；Go 通过运行时调度 goroutine。**
