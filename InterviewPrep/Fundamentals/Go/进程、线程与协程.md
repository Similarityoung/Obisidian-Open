# 进程、线程与协程

## 图示

![进程、线程、协程和 Goroutine 示意图](进程、线程与协程.png)

图中把协程概括为通过 `yield` / `resume` 切换，是便于理解的简化。协程的调度和抢占方式取决于语言及运行时；Go 的 goroutine 也支持运行时异步抢占。

## 问题

进程、线程和协程有什么区别？Go 的 goroutine 属于哪一种？

## 回答

- **进程**是操作系统分配资源和提供隔离的基本单位，拥有独立的虚拟地址空间及进程资源。进程本身不是通常所说的实际执行流。
- **线程**是操作系统调度执行的基本单位。同一进程中的线程共享地址空间和大部分进程资源，但各自有栈、寄存器等执行上下文；线程间共享数据方便，也需要同步来避免竞争。
- **协程**是语言或运行时管理的执行单元，通常比线程轻量。协程如何切换、是否只能主动让出执行权，由具体实现决定；不同语言的协程并不完全相同。
- **Goroutine** 是 Go 运行时管理的并发执行单元。调度器把大量 goroutine（G）复用到操作系统线程（M）上运行，并由处理器（P）提供调度所需的资源；它不是与 OS 线程一一对应的线程。

面试时可以概括为：**进程管资源与隔离，线程负责被操作系统调度执行，协程由语言或运行时管理；Go 用运行时调度 goroutine，并将其复用到 OS 线程上。**
